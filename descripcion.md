# Descripción del proyecto

## Nombre

## Objetivo

Aprender el funcionamiento del control de
versiones y la colaboración en proyectos
de desarrollo de software.

## Herramientas

- Git
- GitHub
- Git Bash
- Visual Studio Code
- GitHub Desktop

## Actividades

Se han realizado ejercicios con commits,
ramas, fusiones y repositorios remotos.
